# Namespaces and directives: answers

## Conceptual

1. Namespaces group related types and avoid name collisions, so the same simple name
   can exist in more than one place. For example `System.Threading.Timer` and
   `System.Timers.Timer` are both named `Timer` but are different types in different
   namespaces.

2. A block-scoped namespace wraps its types in braces and can appear more than once
   per file. A file-scoped namespace is declared with a semicolon
   (`namespace X;`), applies to the whole file, and reduces indentation. The
   limitation: a file can have only one file-scoped namespace, and it must be
   declared before any type.

3. A `using` directive imports names into a file so you can use short type names; it
   has no runtime effect. A `using` statement or declaration manages the lifetime of
   an `IDisposable` and calls `Dispose()` when the scope ends. They share only the
   keyword; their purposes are unrelated.

4. `global using` applies a `using` directive to every file in the project, so you do
   not repeat it. These are usually collected in one file such as `GlobalUsings.cs`,
   or generated by the SDK through implicit usings.

5. Implicit usings is an SDK feature enabled by
   `<ImplicitUsings>enable</ImplicitUsings>`. The SDK adds a set of common
   `global using` directives, including `System`. That is why `Console.WriteLine`
   works without an explicit `using System;`.

6. It imports the static members of `System.Math`, so you can write `Sqrt(2)`
   instead of `Math.Sqrt(2)`. Before: `Math.Sqrt(2)`. After (with
   `using static System.Math;`): `Sqrt(2)`.

7. Any two of: add a `using` alias such as `using WinTimer = System.Timers.Timer;`
   and use the alias; use the fully qualified name such as
   `System.Threading.Timer`; or stop importing one of the two namespaces and qualify
   that one only where needed.

8. `System.Text.StringBuilder`. You need the full name when `System.Text` is not
   imported, or when another imported namespace also defines `StringBuilder` and the
   reference would otherwise be ambiguous.

## Coding

9. File-scoped:

```csharp
namespace Shop.Orders;

public class Order { }
```

Block-scoped:

```csharp
namespace Shop.Orders
{
    public class Order { }
}
```

10. Example:

```csharp
using GList = System.Collections.Generic.List<int>;

var numbers = new GList { 1, 2, 3 };
```

Note that a `using` alias cannot be left open-generic as `GList<T>`; you alias a
specific constructed type such as `List<int>`. To keep it generic you would use the
type directly: `using System.Collections.Generic;` then `List<int>`.

11. With `using static System.Math;` at the top:

```csharp
double h = Sqrt(Pow(3, 2) + Pow(4, 2));
```

12. Example:

```csharp
using var writer = new StreamWriter("out.txt");
writer.WriteLine("hello");
// Dispose() runs automatically at the end of the enclosing scope,
// which flushes and closes the file.
```

`Dispose` is called when execution leaves the scope that contains the `using`
declaration, including when an exception unwinds that scope.
